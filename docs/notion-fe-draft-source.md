**Mr.CUTY UI 와이어프레임 준비 체크리스트**
문서에 명시된 기능을 기준으로 구성하되, 화면 분리 방식과 세부 동작은 아래 설계안을 적용한다. 정책이 불명확한 부분은 마지막의 ‘먼저 정할 사항’에서 결정한다.
**기초 흐름은 고객·음성 선택·직원 업무로 나눈다.**
- **고객 신청:** 홈·상품 목록 → 상품 상세 → 등급·옵션 구성 → 로그인 → 신청·결제 → 신청 결과·출발 상태 확인
- **재방문 고객:** 로그인 → 이전 여행 내역 팝업 → 내 여행 또는 상품 탐색
- **음성 선택:** 음성 입력 시작 → 인식 문장·검색 조건 확인 → 상품 검색·선택 → 고객 신청 흐름으로 연결
- **직원 상품 관리:** 로그인 → 상품 관리 목록 → 상품 등록·수정 → 저장 결과 확인
- **직원 재고 관리:** 재고 목록 → 물품 등록·입고 수량 입력 → 변경된 재고 확인
- **직원 고객 관리:** 고객 목록 → 고객 상세 → 정보 등록·수정 및 이용 이력·단골 등급 확인
설계 가정: 비회원도 상품을 둘러볼 수 있고, 신청 단계부터 로그인한다. 이미 로그인했다면 로그인 단계를 건너뛴다. 로그인 직후 여행 이력 팝업을 닫으면 진행하던 화면으로 돌아온다.
**페이지는 공통 2개, 고객 6개, 직원 4개로 구성한다.**

- 허니문·효도는 그랜드 이상 선택 조건을 표시한다.
- 등급의 기본 구성과 사용자가 변경한 구성을 구별한다.
- 호텔·교통·식사 변경 시 추가금 또는 차감액을 표시한다.
- 선택할 수 없는 항목에는 이유를 표시한다.
- 테마·등급을 바꾸면 기존 옵션이 유지되는지, 초기화되는지 안내한다.
- 프리미엄 기본 제공 샴페인과 추가 옵션이 중복 과금되지 않도록 표시 방식을 정한다.
**고객 화면을 그릴 때 확인할 세부 요소**
- 상품 카드에 테마·여행지·기간·가격을 표시하고, 가격이 1인 기준인지 구분한다.
- 선택한 일정·인원·등급·옵션과 예상 금액을 구성 화면에서 계속 확인할 수 있게 한다.
- 이전 단계로 돌아가도 선택한 내용이 유지되게 한다.
- 신청자 정보는 회원 정보로 채우고, 수정 가능 범위를 정한다.
- 결제 전 기본 금액·옵션 금액·할인 금액·최종 금액을 나누어 보여준다.
- 결제 처리 중에는 중복 신청을 막고, 실패하면 재시도할 수 있게 한다.
- **결제 완료와 출발 확정을 별도 상태로 표시한다.**
- 출발 대기 상태에서는 확정 조건과 현재 모집 상황을 안내한다.
- 출발 확정 여부와 문자 발송 결과를 구별한다.
- 이전 여행 내역이 없는 고객의 안내 문구를 준비한다.
- 로그인 팝업을 닫은 뒤에도 마이페이지에서 여행 내역을 다시 확인할 수 있게 한다.
- 단골 등급·할인율과 이번 신청에 적용된 할인액을 확인할 수 있게 한다.
**음성 입력에는 버튼뿐 아니라 진행 상태가 필요하다.**
- 음성 기능을 어디서 실행할지 정한다: 상품 목록·상세·구성 화면.
- 지원 범위를 정한다: 테마·가격 검색, 상품 선택, 등급·옵션 변경 중 어디까지인지.
- 듣는 중 / 처리 중 / 결과 표시 / 인식 실패 상태를 각각 준비한다.
- 마이크 사용 거부, 음성 없음, 검색 결과 없음 상태를 준비한다.
- 인식한 문장과 실제 적용할 조건을 보여준다.
- “두 번째 상품”처럼 현재 목록을 가리키는 요청의 선택 결과를 명확히 표시한다.
- 잘못 인식했을 때 재입력하거나 직접 클릭해서 이어갈 수 있게 한다.
- 사용자가 음성 입력을 중지할 수 있게 한다.
**직원 화면에서 확인할 세부 요소**
- 상품 등록 시 고객에게 보일 기본 구성·가격·선택 제한을 입력할 수 있게 한다.
- 기존 신청이 있는 상품을 수정할 때, 기존 신청 내용에 미치는 영향을 정한다.
- 신규 물품 등록과 기존 물품 입고를 구분한다.
- 재고 변경 전후 수량을 보여주고, 잘못된 수량 입력을 안내한다.
- 고객 조회·등록·수정 기능을 포함한다.
- 고객의 이용 이력과 단골 등급·할인 정보를 연결해서 보여준다.
- 직원이 단골 등급을 직접 수정할 수 있는지, 자동 계산 결과만 조회하는지 정한다.
- 저장 성공·실패와 수정 중 이탈 상태를 준비한다.
**공통 화면 상태도 와이어프레임에 포함한다.**
- 상단 메뉴, 현재 위치, 뒤로 가기, 주요 실행 버튼의 위치를 일관되게 정한다.
- 로딩 중 / 데이터 없음 / 오류 / 정상 상태를 준비한다.
- 필수 입력 누락과 입력 형식 오류를 해당 입력칸 가까이에 표시한다.
- 로그인 만료 시 재로그인 후 진행하던 화면으로 돌아가게 한다.
- 고객 계정으로 직원 화면에 접근했을 때의 처리를 정한다.
- 색상 외에 문구·아이콘으로도 선택 여부와 상태를 구분한다.
- 모바일 대응 범위를 정하고, 작은 화면에서 구성 요약과 신청 버튼의 배치를 확인한다.
