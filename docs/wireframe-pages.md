## 직원 화면

직원 URL은 미진입 시 A01을 표시하고 고객 시연 역할이면 권한 안내를 표시한다. 직원 시연 역할은 실제 서버 인증·권한 검증을 대신하지 않는다. 메뉴·버튼·닫기는 글자로 표시한다.

| 화면·경로 | 진입 경로 | 표시 정보 | 주요 버튼 | 다음 화면 | 예외 상태 |
| --- | --- | --- | --- | --- | --- |
| S01 `/staff/tours` | 직원 시연·업무 메뉴 | 상품 검색·여행지·테마·기간·1인 가격·운영 상태 예시 | 등록·수정·검색 초기화 | S02 공용 폼 | 빈 검색·초안 초기화, 서버 미저장 |
| S02 `/staff/tours/new`, `/staff/tours/:id/edit` | S01 등록/수정 | 테마·소개·일정·정원·가격, 등급별 호텔/교통/식사/샴페인·가격, 옵션 허용/차액/단위/이유, 물품·제한 | 초안 적용, 실패 상태 보기·재시도, 목록 이동 | S01 | 필수·날짜·정수 가격·옵션 이유 오류, 없는 초안, 적용 전 이탈 확인 |
| S03 `/staff/inventory` | 직원 업무 메뉴 | 물품명·종류·테마·현재 수량 예시 | 신규 등록, 기존 입고/수량 수정, 초안 적용 | 등록/입고 창 → S03 | 음수·소수·안전 정수 초과, 빈 검색, 변경 전후 수량, 실패 상태·재시도·이탈 확인 |
| S04 `/staff/customers` | 직원 업무 메뉴 | 화면 예시 고객 검색, 연락처, 이력·단골 정책 | 등록·상세/수정, 정보·이력·단골 탭, 초안 적용 | 고객 패널 → S04 | 성명/연락처 오류, 빈 이력·검색, 정책 확인 전 단골 읽기 전용, 실패·재시도·이탈 확인 |

상품 수정은 이미 신청한 여행의 구성·가격을 신청 당시 스냅샷으로 보존하고 새 신청부터 적용하는 흐름으로 설계했다. 실제 상품 버전과 예약 스냅샷은 서버 연동 후 적용한다. 직원 초안 수정은 고객 샘플 목록에 전파하지 않는다. 링크 이동·새로고침·패널 닫기에는 미적용 입력 확인이 있고, 브라우저 뒤로 가기와 전체 경로 경계는 추가 검증 대상이다.

## 보관·공통 상태

브라우저 저장 키는 관심상품 ID `cuty:wishes:v1`와 구성 `cuty:drafts:v1`뿐이다. 일정·인원·등급·옵션은 뒤로 이동과 새로고침에서 복원한다. 계정·비밀번호·신청자·동행자·카드정보·DEMO 신청은 저장하지 않는다. 직원 고객 정보와 시연 프로필도 메모리에만 유지한다.

실제 API 요청 로딩·통신 오류·로그인 만료는 미연동이다. 현재 로더는 3D 초기화와 화면 검색 전환을, 결제/직원 실패는 명시적 시연 상태를 표시한다. 빈 결과·필수/형식 오류·없는 경로·접근 역할·선택 제한·브라우저 저장 실패는 초안에서 처리한다. 색만으로 상태를 구별하지 않으며 작은 화면에서는 직원 표만 내부 가로 스크롤한다.

리뷰·장바구니·실제 지도·별도 추천 챗봇은 추가하지 않았다. 홈 섬은 테마를 상징하는 미니어처이며 실제 지리 지도와 다른 용도다. 최신 검증 결과는 [frontend-plan.md](frontend-plan.md)를 확인한다.
