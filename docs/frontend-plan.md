# FE 제작 단계

## 현재: 1단계 — 탐색 가능한 UI 초안

- [x] README와 별표 저장소를 바탕으로 디자인 방향 결정
- [x] 프로젝트별 디자인/작업 가이드
- [x] 반응형 탐색 홈과 네 가지 테마
- [x] 클라이언트 검색과 테마 필터, 검색 결과 없음
- [x] 찜과 찜 목록, localStorage 복구
- [x] 투어·호텔·교통·식사 옵션 및 샘플 가격 합산
- [x] 여행 구성 저장, ‘내 여행’에서 다시 열고 수정
- [x] 페이지 언어·타이틀·설명·파비콘

새 라이브러리 없이 기존 의존성으로 구현했다. 지금은 단일 화면에서 프런트엔드 흐름을 검토하는 단계다.

## 2단계 — 상품 명세와 화면 확정

- 투어 목록/상세, 검색 조건, 네 가지 옵션의 실제 허용 조합 확정.
- 상품별 가격 단위(인당/팀당), 날짜·인원·재고·세금의 계산 주체 확정.
- 상세/검색/찜/내 여행의 URL 설계 후 라우터 도입.
- 실제 상품 이미지와 콘텐츠, 사진 사용 권한 확보.
- 휴대폰/데스크톱 화면 리뷰 후 디자인 토큰 확정.

## 3단계 — API 연동

- 서버 DTO를 `src/types`에 정의하고, UI 모델과 명시적으로 변환.
- `getTours`/`getTour` → 목록·상세, `wish` → 서버 찜 연동.
- 인증과 토큰 갱신, 로딩/실패/재시도/빈 상태 설계.
- 로컬 찜을 로그인 후 병합할지 정책 결정.
- 서버 응답 가격으로 최종 금액 검증. 클라이언트 샘플 계산은 교체.

## 4단계 — 신청과 사용자 영역

- 회원가입·로그인·내 정보, 여행 신청/취소/결제 API 연결.
- 결제 성공/실패·예약 만료·중복 신청 방지 흐름 검증.
- 직원 재고/상품/고객 관리는 고객용 화면과 분리해 설계.

## 수동 검증 시나리오

1. 첫 화면에서 네 가지 테마를 눌러 각 상품만 표시되는지 확인.
2. ‘교토’ 검색 → 1개, 존재하지 않는 키워드 → 빈 결과 → 초기화.
3. 찜 버튼 → 상단 찜한 여행 → 새로고침 후 복구.
4. 카드 열기 → 옵션 네 가지 변경 → 예상 금액 확인 → 내 여행 저장.
5. Escape로 닫기 → 내 여행 → 저장된 옵션 확인 → 수정 후 저장.
6. 390px/1440px에서 가로 넘침·텍스트 겹침·이미지 로드 확인.
7. Tab으로 주요 컨트롤 접근 및 dialog 포커스 제한/복귀 확인.
8. 예약·결제 요청이 발생하지 않고 샘플 안내가 유지되는지 확인.

## 범위

샘플 상품 4개. 데이터와 로컬 저장은 계정에 연결되지 않는다. 검색은 제목·지역·설명에 대한 문자열 검색이다. 날짜·인원·실시간 추천·서버 예약 기능은 다음 단계다.

## 이번 초안 검증 결과 (2026-10-03)

- `npm run build`, `npm run lint`, `git diff --check` 통과.
- 브라우저에서 교토 검색 1개, 없는 키워드 0개 및 초기화 확인.
- 아웃도어/골프 테마 각각 상품 1개 표시 확인.
- 교토 찜과 여행 구성 저장 후 새로고침 복구 확인.

- 1440px 및 390px 뷰포트에서 문서 너비가 뷰포트 너비와 일치함을 확인.
- 여행 사진 5개 로드 성공, 검증 중 수집된 브라우저 콘솔 오류 없음.
- 저장 공간 접근 차단, 전체 키보드 탐색 순서, 실제 API/예약/결제는 이번 브라우저 검증 범위에 포함하지 않음.


## 로고 반영 (v0.2)

사용자 제공 CUTY 로고를 헤더·메인·하단·파비콘에 적용했다. 원본 PNG는 변경 없이 프로젝트에 복사했다. 하늘색·민트색, 파스텔 테마 카드, 둥근 버튼, 구름 장식으로 시각 스타일을 변경했다. 기존 검색·테마 필터·찜·여행 구성의 데이터와 동작은 유지한다.

로고 반영 후 검증: 빌드·린트·diff 체크 통과. 1440px/390px에서 가로 넘침 없음, 로고 4개 로드 확인. 모바일 테마 필터, 옵션 모달 열기, Escape 닫기 확인. 수집된 콘솔 오류 없음.


## 둥근 워드마크와 Liquid glass (v0.3)

- 로고의 C + Fredoka `uty`를 `BrandMark` 컴포넌트로 통합. 헤더·메인·푸터에서 재사용.
- Google Fonts의 Fredoka variable 글꼴을 자체 호스팅하고 SIL OFL 라이선스 동봉.
- 메뉴·검색·테마·상품·모달에 backdrop-filter, 반투명 그라데이션, 유리 가장자리 하이라이트 적용.
- PNG 원본은 그대로 유지하고 SVG 렌더 필터로 흰 배경을 합성.
- CSS liquid glass 구현이며 WebGL 실시간 굴절 라이브러리를 추가하지 않음.
- 1440px, 390px, 320px 가로 넘침 없음. 브라우저 Fredoka 로드 확인. 교토 검색, 저장된 옵션 복구, 모달 Escape 닫기 확인.
