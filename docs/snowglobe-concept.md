# CUTY 스노우볼과 홈 연출 — v0.8

2026-10-08. [Notion — CUTY FE Draft](https://app.notion.com/p/3f2e7df2c0a280ed8942eb6c55dff7cf)와 사용자 제공 새 CUTY 로고를 기준으로 작성했다. 최신 원문의 ‘테마 특징이 확실히 다르게 보여야 한다’, ‘홈은 거의 스크롤하지 않는다’, ‘전환 시 깜빡임을 없앤다’를 구현 기준으로 삼는다. 최신 브라우저 시각 검증은 진행 중이다.

## 네 개의 작은 여행지

테마별 풍경은 이름만 바꾼 같은 모형이 아니라 서로 다른 지형·건축·사람·준비 물품·이동 수단으로 구별한다. 기존 세 무드에서 골프와 트레킹을 분리해 네 테마를 각각 만든다. 가족은 효도 테마의 분위기 표현이다.

테마 기본 제공 사항과 모델 의미를 연결하되 모델만으로 상품 조건을 전달하지 않는다. 실제 포함 사항은 상품 상세·구성 화면에서 텍스트로 확인한다. 인삼 기념품·커플 기념티 등 모든 제공품을 실제 판매 모델처럼 재현했다는 뜻은 아니며, 풍경과 사람·물품의 상징을 통해 테마가 먼저 구별되도록 한다.

섬과 산은 Three.js의 지오메트리·곡선·형상·정점 색으로 만든 **실제 3D 미니어처**다. 이미지 한 장을 회전시키는 연출이 아니며 실제 여행지의 지도·시설 배치를 복원하지 않는다. `modelKit.ts`가 재질·모형 기본 요소를, `themeScenes.ts`가 네 풍경을, `enclosure.ts`가 유리 구·받침·반사 하이라이트를 구성한다. 투명도가 낮은 유리 구와 조명은 풍경의 색과 세부가 흐려지지 않도록 조절한다.

## 한 공간에서의 전환

스노우볼 렌더러는 **R3F 단일 Canvas를 유지**한다. 네 모델을 준비하고 활성 장면만 보여 준다. 약 14초마다 다음 테마로 이동하며 약 1.65초 동안 두 모델의 투명도·크기·높이를 부드럽게 보간한다. 유리 구와 받침·조명·카메라는 그대로 두므로 Canvas를 해제했다가 새로 만드는 방식의 깜빡임을 피한다.

`globe/effects.tsx`는 R3F 기반 효과 확장 지점이다. 테마별 파티클 색·세로 비율·흐름 속도, 별빛, 무드 조명, 프리즘 림과 받침 카우스틱을 `globeEffectPresets`와 두 개의 작은 셰이더에 모으고, 인스턴싱·`useFrame`·React 수명주기로 렌더링한다. 새 효과는 이 컴포넌트 아래에 추가해 단일 Canvas의 demand 렌더링과 화면 밖 일시정지 규칙을 공유한다.

유리 구는 Three.js `MeshPhysicalMaterial`의 transmission·thickness·IOR·dispersion·iridescence를 낮은 강도로 조합한다. 내부 미니어처는 각도에 따라 살짝 굴절되며, 프리즘 셰이더는 가장자리와 이동하는 얇은 반사 띠만 더한다. 수면·받침은 clearcoat로 표면을 분리하고, 재질마다 원래 투명도를 기억해 테마 크로스페이드가 반투명 수면을 불투명하게 바꾸지 않도록 한다.

테마는 직접 선택할 수 있다. 검색 입력에 포커스가 있거나 이용 안내가 열려 있거나 검색 화면으로 이동하는 동안에는 자동 전환을 멈춘다. 모션 정지/재생과 스노우볼 흔들기 버튼을 제공한다. 흔들기는 구가 약하게 흔들리고 입자가 흐트러진 뒤 가라앉는 연출이며 화면 전체를 강하게 흔들거나 스노우볼을 실제로 뒤집지는 않는다.

`prefers-reduced-motion`에서는 자동 전환·비행·부유·입자·등장 효과를 끈다. 사용자가 직접 테마와 검색 조건을 고르는 기능은 유지한다.

## 홈과 검색

고정 헤더의 전체 CUTY 로고·중앙 메뉴, 짧은 테마 문구, 큰 스노우볼, 중앙 조건 검색, 작은 테마/모션 조작을 한 화면 중심으로 배치한다. 아래에 상품·준비 순서·설명 카드 열을 추가하지 않는다. 작은 화면에서는 입력을 쌓고 충분한 터치 영역을 확보한다.

검색에는 테마·출발 희망일·함께할 인원·여행지를 넣는다. 조건은 `/tours`의 URL로 전달되며 여행 구성까지 이어진다. 홈에서 바로 결제하거나 자동으로 상품을 신청하지 않는다. 검색 전환 시 귀여운 비행기 로더를 사용한다.

`Curate Your Travel` 안내는 배경을 흐린 팝업에서 테마 선택 → 취향 구성 → 참여자/시연 신청 → 모집/출발 안내를 순서대로 보여 준다. 단계 선택과 이전·다음 버튼을 제공하며 reduced-motion에서는 자동 모션 대신 직접 이동한다.

## 색과 유리

기본은 로고의 하늘색이며 코랄을 두 번째 강조색으로 정했다. 코랄은 꽃·지붕·검색 버튼·패러글라이더에, 세이지·모래색·아이보리는 풍경의 자연 재질에 사용한다. 날카로운 경계선 대신 색·음영·그라데이션으로 영역을 나눈다.

홈 검색에 [liquid-glass-js](https://github.com/dashersw/liquid-glass-js)의 MIT 셰이더 어댑터를 적용했다. 장식 그라데이션 텍스처만 사용하고 `html2canvas` 캡처는 하지 않는다. 실제 3D 배경의 흐림은 CSS `backdrop-filter`가 맡고 텍스트와 폼은 React의 native 요소로 위에 남긴다. 적용 범위를 전체 페이지의 실시간 굴절로 설명하지 않는다.

## 예약·직원 화면 연결

홈 → 상품 목록 → 상세 → 구성 → 로그인/고객 시연 → 신청·결제 시연 → 신청 상세로 이어진다. 시연에는 대표자와 모든 동행자, 카드·카카오페이·토스페이 성공/실패, 같은 상품·출발일의 결제 완료 인원, D−7 확정/미달 취소 표시가 있다. 실제 결제·문자 발송·자동 환불은 연결 전이다.

직원은 별도 시연 역할과 업무 메뉴를 사용한다. 상품 등급·옵션·물품 편집, 신규 물품/입고 구분과 변경 전후 수량, 고객 정보·이력·단골 패널을 제공한다. 글자·메시지 박스로 구성하고 직원 화면의 아이콘은 표시하지 않는다. 수정은 현재 메모리에만 유지한다.

세부 진입·버튼·예외·미정 정책은 [페이지 구성](wireframe-pages.md)을 따른다. 실제 고객/직원 인증과 서버 API를 명시적 시연 역할로 대신하지 않는다.

## 비용·접근성·후속 확인

3D는 `three` + `@react-three/fiber`를 홈에서 지연 로드하며 별도 UI·후처리 라이브러리는 추가하지 않는다. 현재 측정한 3D 청크는 약 **949.72KB / gzip 255.43KB**이고 Vite 청크 크기 경고가 남는다. 원본 로고 PNG 약 3.4MB도 운영 전 별도 최적화 자산을 검토한다.

픽셀 비율 최대 1.5·약 30fps·demand 렌더링, 정지/비활성 탭/화면 밖 렌더링 중지, 경로 이탈 시 모델·재질·환경 맵 정리를 구현했다. WebGL 초기화 실패에는 테마별 정적 그림을 표시하고 검색을 유지한다. 의미 있는 테마 설명은 접근 가능한 텍스트로 제공한다.

현재 브라우저 검증에서 모델 디테일과 밝기·색, 네 테마 전환·입자·수동 조작, 낮은 화면 높이와 모바일 검색, 콘솔을 확인하고 있다. 실기기 GPU 성능·WebGL 강제 실패·OS reduced-motion·전체 키보드는 실행 여부를 구분해 [제작 계획](frontend-plan.md)에 기록한다.

이전 v0.7의 세 무드·11초·장면 재마운트·비활성 결제·R3F 미사용 기록은 현재 구현 설명으로 사용하지 않는다. 당시 검증은 제작 계획의 접힌 이력에 보존했다.
